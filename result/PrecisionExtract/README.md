# 精准解压

Windows 10 / 11 x64 便携版。将整个 `PrecisionExtract` 文件夹放到本机，双击 `精准解压.exe`。无需安装 Python、Node、Java 或另装解压软件。需要 .NET Framework 4.8（当前 Windows 10/11 通常自带；不支持被移除 .NET 的精简系统）。程序启用 PerMonitorV2 高 DPI，按每块显示器的缩放比例清晰绘制文字。请保留随包提供的 `精准解压.exe.config`。

## 使用

- 选择或拖入 ZIP、RAR、TAR、7Z、GZ、BZ2、XZ、ZSTD 等压缩文件。
- 规则列表固定高度，可滚动。添加规则；Ctrl / Shift 多选后删除；双击或 F2 编辑；Delete 删除选中规则。
- 正则表达式匹配文件名，默认忽略大小写；关闭正则后按完整文件名匹配。任意规则命中即保留。
- 保存目录留空使用“文档\精准解压”。结果放入 `根目录\yyyy-MM-dd\问题N`。各进程通过 Windows 原子创建目录分配编号，不共享临时文件夹。同名文件保存为 `name (2).log`，不覆盖。
- “完成后自动打开结果目录”可勾选，默认开启；取消勾选后不自动打开目录。该开关与 Notepad++ 开关相互独立，保存配置后右键任务也使用此设置。
- 可勾选使用 Notepad++ 新实例打开所有命中文件（`-multiInst -nosession`），不复用已有窗口，也不恢复历史标签页。命中文件过多、超过单次命令行长度时，分批在多个新实例中打开。未安装时可在设置指定路径。
- 执行期间显示 loading；成功、失败、无命中和取消后，任务窗口自动关闭，只使用 Windows 系统通知提醒。系统关闭通知或启用勿扰时，横幅可能不显示。右键任务窗口关闭后，进程仅保留通知所需的 15 秒存活时间，随后自动退出。
- “保存配置”后右键任务读取已保存规则。配置保存在 `%LOCALAPPDATA%\PrecisionExtract\settings.xml`，写入使用进程间锁和原子替换。
- 在“设置”中添加或移除当前用户右键菜单，不需管理员权限。Windows 11 可能需先点“显示更多选项”。移动应用后重新添加菜单，删除应用前移除菜单。
- 右键入口只显示执行中的进度小窗，结束后自动关闭并发送通知，不加载主页面。允许多个独立进程同时工作。
- 任务支持取消；取消或异常保留已提取结果，通过 Windows 通知说明异常。临时展开文件在任务结束前清理；清理失败明确提示路径。

## 边界

嵌套压缩包按扩展名识别，逐层处理，支持 `.tar.gz` 这样的连续打包。无扩展名或伪装成其他后缀的内部压缩包不自动识别。仅抽取匹配文件和需要递归的内部压缩包，不整包落地。匹配针对文件名而非目录路径，结果平铺保存。

加密压缩包当前不提供密码输入，会报告失败。损坏的内层压缩包记录异常并继续其他分支。为避免失控展开，单任务最多累计展开 20 GB、扫描 100000 个条目、嵌套 128 层，超限明确报错。正则每次匹配超时为 1 秒。程序运行时主动清理临时文件；强制结束进程或断电无法保证即时清理。

## 构建

`powershell -ExecutionPolicy Bypass -File .\build.ps1`

使用系统 .NET Framework C# 编译器，解压引擎为官方 7-Zip 26.06 x64。`engine` 文件夹必须随程序保留。引擎许可见该目录中的说明，来源：https://www.7-zip.org/ 。7-Zip 使用 GNU LGPL、BSD 及 unRAR 限制许可；本工具只使用 RAR 解压能力。源代码：https://www.7-zip.org/download.html 。

自动化验证入口（不打开界面或外部软件）：

`精准解压.exe --headless 包.zip --output 输出目录 --rule "\.log$" --report result.xml`

可重复指定 `--rule`，加 `--literal` 使用完整文件名。返回码：0 成功，1 初始化失败，2 有异常，3 无命中。测试脚本：`tests\integration.ps1`。
